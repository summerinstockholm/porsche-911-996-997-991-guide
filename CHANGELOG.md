# Changelog

Все заметные изменения `porsche-911-996-997-991-guide` фиксируются здесь.

## [Unreleased]

### Changed

- возвращена отдельная оценка **ремонтопригодности двигателя**, потерянная при перестройке README на шесть фаз;
- в таблицах всех шести фаз отдельно разведены **задиры/цилиндры**, общий моторный риск, ремонтопригодность `Рем.` и финансовый риск `💸`;
- добавлен общий раздел по ремонтопригодности M96/M97, Mezger-derived, 9A1/MA1 и 991.2 с пояснением, что bore scoring не делает M96/M97 «одноразовыми» моторами;
- основная структура README перестроена из трёх поколений в **шесть самостоятельных покупательских блоков**: `996.1`, `996.2`, `997.1`, `997.2`, `991.1`, `991.2`;
- каждый блок теперь имеет собственные фото, таблицу версий, характерные технические особенности, PPI-акценты, рыночный срез и практический вердикт;
- рыночные ориентиры разделены по дорестайлингу/рестайлингу там, где исходная выборка это позволяет;
- короткая карта линейки также перестроена на шесть фаз;
- отдельно подчёркнуто, что `.1/.2` — распространённая рыночная/энтузиастская маркировка, тогда как Porsche в первичных материалах чаще использует `model update` / `model year`.
- годы фаз переписаны без смешивания календарного года и `MY`; `MY` явно расшифрован как **Model Year / модельный год**, а для переходных лет добавлено правило сверять VIN и конкретную версию;
- отдельно отмечено, что Turbo/GT/RS/Targa могут не совпадать по календарным границам с основной Carrera-family (например, 911 R 2016 года относится к ветке 991.1).
